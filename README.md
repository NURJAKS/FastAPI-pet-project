# Student/Group FastAPI Service

## Описание
Веб-приложение на FastAPI для управления студентами и группами с использованием PostgreSQL (через SQLAlchemy), Alembic для миграций и кэшированием запросов к Redis. Включена поддержка авторизации, ролей пользователей, ограничения прав и rate limiting.

## Возможности
- Регистрация и логин пользователей
- Роли пользователей и разграничение доступа
- CRUD для студентов и групп
- Кэширование данных студентов и отдельных студентов в Redis
- Инвалидация кэша при изменении данных
- Alembic-мизации БД
- Ограничение rate limit на отдельные роуты

## Структура проекта
- `api/` — эндпойнты FastAPI
- `models/` — модели SQLAlchemy
- `db/` — настройки базы данных и клиент Redis
- `utils/` — утилиты для авторизации, OAuth, limit и т.д.
- `alembic/` и `alembic.ini` — миграции Alembic
- `requirements.txt` — зависимости

## Быстрый старт

### 1. Клонировать проект
```bash
git clone https://github.com/NURJAKS/pet-project.git
cd pet-project
```

### 2. Установить зависимости
```bash
pip install -r requirements.txt
```

### 3. Заполнить настройки подключения:
- `db/database.py` — параметры подключения к PostgreSQL
- `db/redis_client.py` — параметры подключения к Redis

### 4. Применить миграции
```bash
alembic upgrade head
```

### 5. Запустить приложение
```bash
uvicorn api.app:app --reload
```

## Примеры запросов

### Получить список студентов (с кешированием):
```
GET /students
```

### Получить одного студента:
```
GET /students/{id}
```

### Добавить студента:
```
POST /students
{
    "name": "Иван Иванов",
    "age": 21,
    "group_id": 1
}
```

## Тестирование
Рекомендуется использовать Postman или curl для ручных запросов к API, или pytest для автоматических тестов.
